# 辅助数据流方法论（五粮液吸筹跟踪库 · v1.0）

> 设立：2026-10-16 ≈11:00 +08:00（对话 31 / T7）。用户指令："其他的也要搞 不单单是技术分析 新闻 政策 库存 销售价格 市场情绪等都要给我搜了作为辅助 并形成方法论 入库 我要用这些信息作为数据流来分析"。
> 定位：与技术电池（01）并行的**非技术面数据流**，作为辅助校验；不覆盖框架判定，只改变置信度与完成度标尺的读数。

## 数据流六类（S1-S6）

| 流 | 内容 | 采集方式 | 关键指标 |
|---|---|---|---|
| **S1 政策与监管** | 白酒消费税（计税基准/一品一码试点）、禁酒令执行纠偏、促内需政策、地方产业政策（宜宾）、监管规则 | web 检索固定查询模板 | 方向 +/0/−、生效日期 |
| **S2 产业价格链（核心高频）** | 普五（八代）批价、终端成交价、厂家挺价政策（红线/控货/补贴）、飞天茅台批价（行业锚）、1618/39度/系列酒 | 检索"今日酒价/百荣/媒体报道" | 批价绝对值（元/瓶）、月度方向 |
| **S3 库存与动销** | 渠道/终端库存月数、双节动销同比、公司成品酒库存（财报硬数据）、合同负债、回款考核方式转变 | 检索 + 半年报/三季报 | 库存月数、动销同比 |

| **S5 新闻与舆情** | 重大事件、媒体叙事方向（如"卖不动"vs"动销超预期"）、机构观点、信任危机类事件 | 检索 | 叙事方向、事件日历 |
| **S6 情绪与估值代理（全自动，本地计算）** | 52 周位置、价格/PE 250 日分位、20 日波动率分位、量能分位、换手分位、ADX、布林带宽分位、量价相关、缺口结构、斐波那契回撤进度 | 库内 250 日数据现算 | 各分位值 |

## 评分规则（S1-S5）
每条记录五元组：`{方向: +2/+1/0/−1/−2, 权重 w: 1-3（重要性）, 新鲜度: 数据日期, 来源: URL, 置信: 高/中/低}`。
- 置信低的条目权重减半并标注 ⚠。
- **AuxScore** = Σ(方向×权重) / Σ(权重) × 100，范围 ±100；>0 = 辅助面偏多，<0 = 偏空。
- 每条目必须带**新鲜度**；超过 60 天未更新的条目降权 0.5 并标注「陈旧」。

## 与技术电池的整合规则
1. S6 自动并入技术电池文件（01）的 v2 节，同时摘录关键分位到 04。
2. AuxScore 只用于**三种操作**：①校验技术信号（背离时降置信）②调整完成度标尺读数 ±10% ③更新"可证伪清单"候选条目。**不直接产生 BUY/SELL**。
3. 产业链硬指标（批价、库存）与技术面矛盾时，以技术面定框架行为、以产业链面定叙事（写入 00-结论 的「矛盾调和」）。

## 固定检索模板（每次 Run 执行，S1-S5 各一条）
1. `八代五粮液 批价 2026年X月 今日酒价`（S2）
2. `白酒 政策 消费税 禁酒令 促消费 2026年X月`（S1）
3. `五粮液 渠道库存 动销 中秋/国庆/春节`（S3）
4. `五粮液 大宗交易 龙虎榜 回购 2026年X月`（S4）
5. `五粮液 最新消息 三季报/公告`（S5）

## 运行流程（并入现有比对协议）
每次 Run：先跑 S6（本地秒出）→ 执行 5 条检索模板（S1-S5）→ 写 `04-辅助数据流.md`（六类逐条五元组 + AuxScore + 与技术面校验结论）→ `snapshot.json` 的 `aux_stream` 与 `battery_v2` 字段更新 → 跨日比对时**批价/库存/户数优先级最高**。
