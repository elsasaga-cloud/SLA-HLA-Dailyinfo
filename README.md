# 海澜之家 / 海尔智家：90 个交易日逐日数据

本仓库只包含用户指定的两只股票：

- 海澜之家（600398）
- 海尔智家（600690）

数据截至 **2026-08-21（星期五）**，即 2026-08-24 抓取时最近一个完整收盘的交易日。每只股票均为 **90 个实际交易日**，日期范围是 **2026-04-14 至 2026-08-21**。

## 直接使用的逐日文本

这两个文件是主要交付物，均有 90 个完整的中文逐日数据块：

- [`data/daily_text/600398_海澜之家_90d.txt`](data/daily_text/600398_%E6%B5%B7%E6%BE%9C%E4%B9%8B%E5%AE%B6_90d.txt)
- [`data/daily_text/600690_海尔智家_90d.txt`](data/daily_text/600690_%E6%B5%B7%E5%B0%94%E6%99%BA%E5%AE%B6_90d.txt)

每个交易日的数据块包含：

- 日期、股票名称和代码；
- 收盘价、涨跌额、涨跌幅、开盘、昨收/除权参考价、最高、最低、涨停、跌停和振幅；
- 换手率、量比、成交量和成交额；
- PE、PB、总市值、流通市值、内盘和外盘字段；
- 获利比例、平均成本、90%/70% 成本区间及集中度；
- 5 日涨跌额和涨跌幅；
- MA5、MA10、MA20、MA30、MA60、MA90，以及各均线相对上一交易日的方向。

> PE、PB、总/流通市值及内/外盘属于历史时点快照，所用历史 K 线接口不能可靠返回这些旧值。文本仍保留这些字段，并明确写为 `N/A（历史 K 线不提供，未以当前值回填）`。仓库没有用 2026-08-24 的当前值冒充过去 90 日的数据。

## 数据源选择

两只股票的日线字段及筹码计算输入全部采用同一个来源：**东方财富历史 K 线接口**：

```text
https://push2his.eastmoney.com/api/qt/stock/kline/get
```

请求使用 `klt=101`（日线）、`fqt=0`（不复权）及同一组 `f51`–`f61` 字段。腾讯接口原本是首选，但其标准历史日线不能同时提供逐日成交额、振幅和换手率；只用腾讯会再次变成不完整的 OHLCV 数据，而混用来源也不符合两只股票同源的要求。因此最终数据统一使用东方财富。

字段映射：

| 接口字段 | 仓库字段 | 含义 |
| --- | --- | --- |
| `f51` | `date` | 日期 |
| `f52` | `open` | 开盘价 |
| `f53` | `close` | 收盘价 |
| `f54` | `high` | 最高价 |
| `f55` | `low` | 最低价 |
| `f56` | `volume_lots` | 成交量（手） |
| `f57` | `amount_yuan` | 成交额（元） |
| `f58` | `amplitude_pct` | 振幅（%） |
| `f59` | `change_pct` | 涨跌幅（%） |
| `f60` | `change_amount` | 涨跌额（元） |
| `f61` | `turnover_rate_pct` | 换手率（%） |

完整来源、算法参数、日期和 SHA-256 校验值见 [`data/eastmoney/metadata.json`](data/eastmoney/metadata.json)。

## 筹码分布与技术指标

### 筹码分布

筹码分布不是用短短 90 日数据直接估算。每个目标交易日都使用截至该日的滚动 **210 个交易日** OHLC 和换手率，按东方财富网页 CYQ 算法计算：

1. 价格范围划分为 150 个档位；
2. 当日筹码按 `(开盘 + 收盘 + 最高 + 最低) / 4` 构造三角分布；
3. 按换手率衰减旧筹码并加入当日筹码；
4. 从累积分布读取获利比例、平均成本、90%/70% 成本区间和集中度。

为给第一个目标日提供完整 210 日窗口，每只股票另存了 209 日预热数据。预热数据只用于计算，不计入“90 个交易日”的交付数量。

算法已对照用户给出的海澜之家样例，例如：

| 日期 | 获利比例 | 平均成本 | 90% 成本区间 | 70% 成本区间 |
| --- | ---: | ---: | ---: | ---: |
| 2026-07-28 | 74.28% | 5.88 | 5.50–6.21 | 5.68–6.12 |
| 2026-08-06 | 74.36% | 5.90 | 5.51–6.24 | 5.69–6.14 |
| 2026-08-07 | 73.54% | 5.90 | 5.51–6.24 | 5.69–6.14 |
| 2026-08-21 | 50.45% | 5.90 | 5.52–6.24 | 5.69–6.14 |

### 除权与均线

技术指标按“当日可见”的前复权状态计算，避免把未来分红提前应用到更早的历史快照：

- 海澜之家：从 2026-05-11 起，对此前价格减 0.41 元；
- 海尔智家：从 2026-08-21 起，对此前价格减 0.87 元。

除权日的涨跌额、涨跌幅、振幅及涨跌停价以除权参考价计算。该处理与东方财富前复权 K 线在对应日期的两位小数价格一致。

其他计算定义：

- **量比** = 当日成交量 / 前 5 个交易日成交量算术平均值；
- **5 日表现** = 当日收盘价相对 5 个交易日前收盘价；
- **MA(n)** = 最近 n 个交易日调整后收盘价的算术平均值；
- **趋势方向** = 当日 MA 与上一交易日同周期 MA 比较所得的“向上 / 向下 / 持平”；
- **涨跌停价** = 参考价的 ±10%，按 0.01 元四舍五入。

## 来源 CSV

每只股票有以下计算输入：

```text
data/eastmoney/<代码>_<名称>_kline_90d.csv
data/eastmoney/<代码>_<名称>_chip_warmup_209d.csv
data/eastmoney/<代码>_<名称>_volume_warmup_5d.csv
```

- `kline_90d.csv`：90 个交付交易日的完整日 K 字段；
- `chip_warmup_209d.csv`：每个滚动 210 日筹码窗口及 MA90 所需的预热 OHLC/换手率；
- `volume_warmup_5d.csv`：第一个交付日计算量比所需的前 5 日成交量。

## 重新生成与抓取

仅用仓库中已保存的数据重新生成逐日文本（无需联网或第三方包）：

```bash
python scripts/generate_daily_text.py
```

从东方财富重新抓取固定截止日的 299 个交易日，并重建全部文本：

```bash
python scripts/fetch_eastmoney_90d.py --end-date 20260821
```

抓取脚本严格限定为上述两只股票，对两只股票使用同一接口、相同字段和相同拆分规则。若将来改用新的截止日期，应同时核查截止区间内是否新增除权事件，再更新生成脚本中的除权配置。

运行数据完整性、筹码样例和文件校验测试：

```bash
python -m unittest discover -s tests -v
```
