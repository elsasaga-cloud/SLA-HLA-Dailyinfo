# SLA-HLA-Dailyinfo

海澜之家（600398）和海尔智家（600690）的腾讯证券历史日 K 数据。

## 已抓取数据

| 股票 | 文件 | 交易日数 | 日期范围 |
|---|---|---:|---|
| 海澜之家（600398） | [`data/tencent_qfq/600398_海澜之家_90d.csv`](data/tencent_qfq/600398_%E6%B5%B7%E6%BE%9C%E4%B9%8B%E5%AE%B6_90d.csv) | 90 | 2026-04-14 ～ 2026-08-21 |
| 海尔智家（600690） | [`data/tencent_qfq/600690_海尔智家_90d.csv`](data/tencent_qfq/600690_%E6%B5%B7%E5%B0%94%E6%99%BA%E5%AE%B6_90d.csv) | 90 | 2026-04-14 ～ 2026-08-21 |

- **唯一数据源：** 腾讯证券 `web.ifzq.gtimg.cn`
- **周期：** 日 K，90 个已完成的 A 股交易日（不是简单的 90 个周一至周五）
- **复权方式：** 前复权（`qfq`），与参考代码中的腾讯 K 线参数一致
- **字段：** `date, open, close, high, low, volume_lots`
- **成交量单位：** 手（1 手 = 100 股）
- **抓取时间：** 2026-08-24 12:10（北京时间）

2026-08-24 抓取时当天仍在交易，因此没有把未收盘的 2026-08-24 K 线混入数据，截止日取 2026-08-21。详细来源 URL、字段说明和文件校验值见 [`data/tencent_qfq/metadata.json`](data/tencent_qfq/metadata.json)。

> 注意：CSV 价格均为腾讯当前计算的前复权价格，不等于除权日前当时看到的不复权行情价。例如海尔智家在 2026-08-21 除息后，此前价格会按前复权口径调整。这也是 2026-08-07 的 CSV 收盘价 `21.056` 与当天实时行情记录 `21.93` 不同的原因。

## 更新数据

脚本只处理这两只股票，并且只请求腾讯证券，不会切换到新浪、东方财富等其他来源：

```bash
python scripts/fetch_tencent_90d.py
```

复现本次固定截止日的数据：

```bash
python scripts/fetch_tencent_90d.py --end-date 2026-08-21 --count 90
```

脚本在交易日 16:00（北京时间）前运行时会自动避开尚未收盘的当日 K 线。
