# 五粮液 / 海澜之家 / 海尔智家：90 个交易日逐日数据

包含：

- 五粮液（000858）
- 海澜之家（600398）
- 海尔智家（600690）

每只股票各 **90 个交易日**，日期范围为 **2026-04-14 至 2026-08-21**。2026-08-24 抓取时当天尚未完整收盘，因此截止到最近完整交易日 2026-08-21。

## 主要交付文件

- [`data/daily_text/000858_五粮液_90d.txt`](data/daily_text/000858_%E4%BA%94%E7%B2%AE%E6%B6%B2_90d.txt)
- [`data/daily_text/600398_海澜之家_90d.txt`](data/daily_text/600398_%E6%B5%B7%E6%BE%9C%E4%B9%8B%E5%AE%B6_90d.txt)
- [`data/daily_text/600690_海尔智家_90d.txt`](data/daily_text/600690_%E6%B5%B7%E5%B0%94%E6%99%BA%E5%AE%B6_90d.txt)

三个文件都严格使用用户给定的逐日文本排版，不添加标题、章节名或字段说明。每个数据块均按以下顺序输出：

1. `Date` 和 `股票数据`；
2. 价格、涨跌额和涨跌幅；
3. 今开、昨收、最高、最低；
4. 涨停、跌停、换手率和量比；
5. 成交量、成交额、动态市盈率和市净率；
6. 总市值、流通市值、振幅、内盘和外盘；
7. 筹码获利比例、平均成本、90%/70% 成本及集中度；
8. 5 日涨幅；
9. MA5、MA10、MA20、MA30、MA40、MA50、MA60、MA70、MA80、MA90及上升/下降方向。

测试中保存了用户给出的 **海澜之家 2026-08-21 完整文本块**，生成结果必须逐字符一致，否则测试失败。

## 数据与计算口径

### 日行情

三只股票统一使用东方财富历史日 K 接口的同一组字段：

```text
https://push2his.eastmoney.com/api/qt/stock/kline/get
```

| 字段 | 含义 |
| --- | --- |
| `f51` | 日期 |
| `f52` | 开盘价 |
| `f53` | 收盘价 |
| `f54` | 最高价 |
| `f55` | 最低价 |
| `f56` | 成交量（手） |
| `f57` | 成交额（元） |
| `f58` | 振幅 |
| `f59` | 涨跌幅 |
| `f60` | 涨跌额 |
| `f61` | 换手率 |

量比采用：

```text
当日成交量 / 前 5 个交易日成交量平均值
```

### 动态市盈率、市净率和市值

这些字段不再输出 `N/A`：

- **动态市盈率**：总股本 × 收盘价 / 当时已生效的年化归母净利润；
- **市净率**：收盘价 / 每股净资产口径；
- **总市值**：总股本 × 收盘价；
- **流通市值**：流通股本 × 收盘价。

动态市盈率在一季报披露前采用当时最近已披露年度的归母净利润，披露后采用 2026 年一季度归母净利润 × 4。三只股票使用完全相同的方法。

### 筹码分布

每个目标日使用截至该日的滚动 **210 个交易日** OHLC 和换手率，按东方财富 CYQ 网页算法计算：

- 获利比例；
- 平均成本；
- 90% 成本范围及集中度；
- 70% 成本范围及集中度。

海澜之家样例校验：

| 日期 | 获利比例 | 平均成本 | 90% 成本 | 70% 成本 |
| --- | ---: | ---: | ---: | ---: |
| 2026-07-28 | 74.28% | 5.88 | 5.50-6.21 | 5.68-6.12 |
| 2026-08-06 | 74.36% | 5.90 | 5.51-6.24 | 5.69-6.14 |
| 2026-08-07 | 73.54% | 5.90 | 5.51-6.24 | 5.69-6.14 |
| 2026-08-21 | 50.45% | 5.90 | 5.52-6.24 | 5.69-6.14 |

### 5 日涨幅及 MA

为完全复现给定格式中 2026-08-21 的数值，技术指标采用原抓取程序的快照口径：

- 当前快照日的价格不放入 MA 序列；
- `5日涨幅` 使用前一完整 K 线相对再往前 5 个交易日的涨幅；
- MA 使用快照日前已完成的 n 个交易日收盘价；
- “上升/下降”比较该 MA 与再前一交易日的同周期 MA。

这可复现样例中的：

```text
5日涨幅: 0.33%
MA5: 5.94 (上升), MA10: 6.00 (下降), ... MA90: 5.98 (下降)
```

## 重新生成

使用仓库内数据重新生成文本：

```bash
python scripts/generate_daily_text.py
```

重新抓取固定截止日并生成：

```bash
python scripts/fetch_eastmoney_90d.py --end-date 20260821
```

运行校验：

```bash
python -m unittest discover -s tests -v
```
